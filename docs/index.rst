====================
MaatLog ドキュメント
====================

MaatLog は、Sphinx のドキュメントプロジェクトを静的ブログに変える拡張です。
目的に応じて次の導線から参照してください

- はじめて利用する場合は「初めての方」から順に読み進めてください
- やりたいことが決まっている場合は「目的別ガイド」から該当するページを参照してください
- ビルドの警告やエラーが出た場合は「トラブルシューティング」で症状から対処を調べてください
- 仕組みや設定項目の詳細は「リファレンス」を参照してください
